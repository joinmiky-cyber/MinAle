# MinAle - Localized Business Discovery Platform

MinAle is a localized business discovery platform focused on Ethiopian cities.

## Project Structure

- `backend/`: Django REST Framework API with PostgreSQL (Supabase) and Django Admin.
- `frontend/`: Next.js web application with Tailwind CSS and shadcn/ui.

## Tech Stack

- **Backend**: Django, DRF, SimpleJWT, PostgreSQL (Supabase).
- **Frontend**: Next.js (App Router), Tailwind CSS, shadcn/ui, Lucide React.
- **Database**: Supabase PostgreSQL.
- **Storage**: Supabase Buckets.

## Deployment

- **Backend**: Railway
- **Frontend**: Vercel
